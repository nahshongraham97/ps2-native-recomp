## Connected implementation

- Actual `retail_main.cpp` calls `initialize_retail_mode_objects`; the
  definition in `retail_saved_profile_bindings.cpp` now invokes the SAME
  Session-owned `NativeRetailSavedProfileRecords`.
- The first-two child bodies reuse the verified native245CB0 reset and its
  existing localized data, masks, Working state and command/preset defaults.
  Their source metadata/publication order is retained. Xbox-proved extra
  identities use the same typed values, not the donor35E0 memory layout.
- Names and statistics publish by pair; the first-two preset aliases publish
  after their source metadata. Xbox extra-player presets are not invented.
  Input mappings, parent in-use flags and separate player-status words are
  not cleared by this startup function; those belong to later callers.
- `NativeRetailPublishedProfileFields` retains the real Session and resolves
  current native name/third counter pair/five results/six preset slots.
  Capabilities survive value reset; borrowed strings/views expire on mutation.
  Existing publication is never cleared before reinitialization.
- Failed child resets preserve earlier effects/publications, mark the
  ordinary after-effect failure and do not report ready. Readable prefixes
  remain inspectable; new writes/replays reject the failed owner.
- Counter updates use exact full32-bit equality1 and defined unsigned wrap.
  Signed/unsigned source loop issues cannot overflow the bounded0..3 native
  participant domain. Invalid host scopes/selectors, moved references,
  foreign owners, wrong threads and reentry fail by name.

The PS2 codec, external sizes/checksums and native store are unchanged. There
is no new save format, extra serialized card parent or guest resource ceiling.
No mathematical, camera, graphics, packed-time or audio implementation changed.
