# Offline native movie asset inventory fixture — 2026-11-19

New `tests/test_native_movie_inventory.cpp` is frozen for root build; no build, codec run, output presentation, audio/device activity or game execution was performed by this implementation agent. Existing media service source is unchanged. Root owns CMake and execution.

CLI: `test_native_movie_inventory explicit_codec_library_directory MOVIEPS2_root`. Link the existing `mka_native_media` target and the existing test SHA256 helper dependency BCrypt; no PS2runtime, OpenGL or audio device is needed. The fixture writes JSONL only, with progress/codec diagnostics on stderr. It writes no raw source media, decoded planes or PCM files.

Recursively collect actual regular files with ASCII-case-insensitive `.SFD` extension; do not follow directory symlinks. Sort exact UTF-8 relative keys deterministically, then construct one explicit NativeMovieAssetStore catalog of key→same actual relative path. No inferred N/W aliases, basename fallback, directory search inside open, or claims of retail caller reachability. Catalog identity/containment failure is a named global failure, not a bypass to direct filesystem decoding. Filesystem traversal/read errors fail rather than claim complete inventory.

Each source is opened once through the catalog. Read/hash every source byte through that opened NativeMovieAsset; move the same already-open asset into NativeMovieDecoder, whose owned-asset API resets to bytezero without reopening. Drain until actual decoder end (including decoder flush), preserving named errors and continuing to every later catalog asset. Failed output hashes describe only the decoded prefix; no failed or empty stream becomes a complete success. Nonzero aggregate exit if any asset fails. Source hash describes the bytes read before decoding, not a snapshot guarantee against concurrent external modification.

Per asset: SHA256 and byte count of the complete source; video/audio decoder frame counts; per-channel sample-frame total and scalar sample total; SHA256 and byte counts of all owned YUV/PCM outputs, concatenated in frame order (Y/U/V planes; channel vectors S16LE respectively). Exact LOGON.SFD/TITLEN.SFD/OPENINGN.SFD compare the retained independent full SHA/count/FNV/raw+best timestamp goldens. No similarly named subpath or alternate N/W name inherits a golden. All other assets are decode-support observations, not independently verified retail fidelity. API unsupported streams/frames remain named failures.

Raw and best timestamp observations are separate: missing count, first/last/min/max and delta histogram per exact rational timebase. Negative/repeated deltas remain visible rather than normalized. Video metadata records every observed width/height, SAR and native color range/space/primaries/transfer tuple; audio metadata records every sample-rate/channel-count pair. Nominal video frame rate is **not exposed by MovieVideoFrame API**, so JSON explicitly marks it unavailable and reports observed timestamp cadence instead. No guessed FPS, scheduling, A/V synchronization, physical presentation or audible completion follows these observations.

Root should retain JSONL plus stderr, exact exit/executable/source/compiler/library identities and library hashes for any run. The implementation-time filename snapshot below does not certify successful decoding, expected byte identity or all retail path coverage.
