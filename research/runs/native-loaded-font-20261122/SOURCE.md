### Widths, control flow and effect order

- `16FC70` uses SLL/ADDU to index24-byte source records; only source selector0
  is ported by this binding. It does not expose unsafe negative table indexing.
- `16FCF4` initializes the stack MET length in the texture-call delay slot.
  Null texture skips MET/sampler/cache writes; successful texture publishes
  even if MET is null.
- ADDIU's immediate is signed. The sampler masks at16FD20..44 produce low16
  `3301` while preserving the original high16 word. The independent pure
  expected cases use literal upper-word results, not the implementation's
  expression.
- `1CFCA0` clears TEX1 sampling bits5..8. Filter1 keeps them0; the taken
  filter2 branch-likely executes its OR60 delay slot (MMAG/MMIN linear).
  `1D3584..35C8` sets each clamp bit for address3. `1D38F0..3910` emits
  these words as TEX1 address14 and CLAMP address08. The native implementation
  maps only the reached non-mip filter1/2 and address1/3 modes; others fail.
  These are offline source explanations, not runtime chip/register state.
- The supported original atlas headers carry metadata1101 and non-mip raster
  profiles. `3015E0` changes only filter to2, giving1102. The font-zero
  update then selects3301.
- `3011D0` relocates all directory metadata before the texture loop, then
  invokes `3DE190`, then writes converted. Native CPU staging performs no
  GPU effects and never publishes converted by itself. Required actual GPU
  work is not skipped on allocation/upload failure.
- Unsigned type masking/range arithmetic and wrapping group-index additions
  remain in the existing CPU owner. No new SIMD/math kernel is adopted.
- NativeMainReentry is propagated instead of being stored in an error latch.
  Ordinary failed GPU conversion is sticky until explicit resource retirement.
